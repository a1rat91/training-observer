# Как пользоваться demo

Откройте `http://localhost:4200/record` после `npm start`.

## Записать тренировку

1. На странице **Запись** дождитесь формы и статуса распознанного экрана. Нажмите **Начать запись**.
2. Заполните поля. Для Input/Select/ComboBox выйдите из поля: во время ввода журнал не фиксирует каждую букву.
3. Перейдите по нужным экранам. Начальные checkbox/radio попадут в запись автоматически, включая false.
4. Выстройте нужную итоговую картину отметок. История останется в журнале, а в сценарий попадёт последнее значение.
5. Нажмите **Завершить запись**. Последнее редактирование будет подтверждено и запись сохранится в этом браузере.

Справа карточки показывают то, что прочитала библиотека. Это диагностика наблюдения, не редактор ожидаемого ответа.
«Показать в форме» подсвечивает текущий элемент. Сырые данные находятся под сворачиваемой диагностикой.

## Настроить ожидания

1. Откройте **Настроить тренировку** → **Создать ожидания из записи**.
2. Для каждого экрана укажите задание и сообщение неправильного перехода.
3. Для каждого поля задайте ожидаемое значение и сообщение ошибки. Можно включить **Не проверять это поле**.
4. Нажмите **Сохранить сценарий для ученика**.

Ожидаемый false означает «должен оставаться выключенным». Он не исключает поле из проверки. Для ComboBox ожидается
отображаемый текст; выбранный вариант и такой же ручной ввод равнозначны, если сам виджет сохраняет этот текст после
выхода. Number сравнивается по отображаемой строке.

Редактор пока не поддерживает полноценные группы, произвольные ветки и импорт через отдельную форму. Radio отображается
как набор boolean-ожиданий на варианты. Эти расширения находятся в плане MVP.

## Удалить ненужную строку

После остановки записи нажмите **Удалить** у строки. **Отменить удаление** возвращает предыдущий документ до
перезагрузки страницы или начала новой записи. Изменённый журнал сохраняется в браузере.

После изменения журнала пересоздайте ожидания. Правки текущего черновика сохраняются для оставшихся полей; ранее
загруженная публикация при пересоздании заменяется новым черновиком. Затем явно сохраните сценарий. Удаление само по
себе не меняет тренировку ученика.

Удалённая граница с оставшимися полями блокирует компиляцию. Общий пропуск наблюдения удалить нельзя: неизвестно, какие
действия пропущены. Скопировать запись можно через раздел **JSON записи**.

## Пройти тренировку

Откройте **Тренировка** (`/learn`) или ссылку после сохранения. Наблюдение запускается автоматически.

- Поля текущего экрана можно заполнять в любом порядке.
- Уже заполненные правильные ответы засчитываются при входе. Неправильные исходные значения не вызывают alert.
- Изменённые Input/Number/Select/ComboBox проверяются после blur.
- Изменение checkbox/radio на неправильное значение вызывает заданный Taiga Alert.
- Неправильный переход не засчитывается. Можно вернуться и продолжить с восстановленными ответами.
- Нельзя пройти дальше, оставив обязательные ожидания невыполненными.

Сообщение **Тренировка завершена** означает, что ожидания последнего шага выполнены. Наблюдение продолжает работать,
поэтому последующее изменение ответа может снять выполненность. Reload начинает новую попытку.

## Другие страницы и хранение

**Контролы** (`/controls`) — каталог для ручной проверки распознавания. Это не дополнительная админка. Нагрузочные и
multi-MF fixtures доступны внутри него по `?fixture=load` и `?fixture=microfrontends`.

Запись и публикация хранятся в localStorage только этого браузера/профиля/адреса. Другой браузер не получает сценарий
автоматически. Backend в demo отдаёт только тестовую форму; серверного хранилища обучения пока нет. Старые записи не
дополняются новыми правилами автоматически: после добавления записи начальных checkbox/radio нужно записать новый
пример, чтобы включить ранее отсутствовавшие ожидания.
