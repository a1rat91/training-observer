# Рефакторинг читаемости

> Архив: история разработки. Описывает состояние на момент написания, не текущий API.
> Актуальные документы — в [указателе](../README.md). Для работы с проектом этот файл не требуется.

Цель: сохранить поведение и JSON v1, сделать маршрут чтения библиотеки понятным без истории разработки.

1. Выделить предметные enum, типы документов и общие правила значений.
2. Разделить runtime на переходы, оценку полей и память уведомлений; упростить регистратор.
3. Выделить общую проверку контрактов без конструирования фиктивных записей.
4. Разделить Angular-фасад и механизм подтверждения blur; упорядочить модули наблюдения.
5. Ввести единое форматирование, описания назначения/алгоритма модулей и читаемый публичный API.
6. Написать актуальную архитектуру, руководство интеграции и интерактивное объяснение.
7. Проверить чистое ядро, полную браузерную регрессию и production-сборку.

Паттерны: Facade для Angular API, Adapter для DOM-контролов, Observer для публикаций,
композиция для runtime. Иерархии классов и State-классы на каждый статус не вводятся без необходимости.
Оптимизация и новые возможности из MVP в этот рефакторинг не входят.

## Фактический результат

- Core разделён на capture/controls/observation/screen/highlight, модели — отдельная pure entry point.
- Recording, runtime и contracts вынесены в независимые Nx/npm-пакеты. Запрещённые зависимости проверяются автоматически.
- Runtime скомпонован из координатора переходов, FieldEvaluator и FeedbackTracker.
- Общие значения/validation убрали дублирование и фиктивную запись при парсинге сценария.
- Angular-фасад делегирует blur отдельному модулю; шаблоны/стили вынесены из компонентов; storage signals readonly.
- Введены строковые enum, Prettier и единый unit runner для TypeScript.
- В каждом пакете/entry point есть README; комментарии исходников пакетов и demo на русском.
- Корневые README/ARCHITECTURE переписаны; добавлены руководства разработчика и пользователя.

Изменение исходных импортов намеренное: запись и runtime больше не реэкспортируются из core.
JSON v1 и ключи сохранения остаются совместимыми.
