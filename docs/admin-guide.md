# Как пользоваться админкой сейчас

Откройте `/record`. Слева работает целевое приложение, справа — админка.

## 1. Запишите действия

Нажмите **«Начать запись»** и выполните нужный workflow слева. После ввода текста выйдите из поля — например, через Tab.
До выхода из поля текст ещё не считается завершённым вводом.

Во время записи доступны **«Остановить запись»**, журнал и настройки наблюдаемых областей. Редактор и выбор вариантов
появятся после остановки: выбор элементов перехватывает клики и поэтому не должен одновременно записывать реальные
действия. Настройку сохранения значений выбирают до начала записи.

## 2. Проверьте журнал

Нажмите **«Остановить запись»**. Удалите лишние действия; ошибочное удаление можно отменить. Начинать запись повторно
для редактирования не нужно: эта кнопка создаст новый журнал вместо текущего.

После остановки можно пользоваться приложением и возвращаться на нужные экраны — эти действия больше не записываются.

## 3. Подготовьте сценарий

В блоке **«Подготовка сценария»**:

1. Проверьте последнее действие, до которого должен дойти ученик. По умолчанию выбрано последнее записанное.
2. Нажмите **«Выбрать результат в приложении»** и укажите видимый признак успеха. Остановка записи сама по себе не
   доказывает, что действие в приложении завершилось успешно.
3. В **«Экраны обучения и переходы»** отметьте действия, открывающие следующий этап, и их результаты. Например, «Далее»
   переводит к новым полям; просмотр справки может остаться заданием того же этапа.
4. Нажмите **«Создать черновик сценария»**. В каждой карточке проверьте текст задания, подсказку, ожидаемое значение и
   optional/зависимости. Без явных зависимостей поля внутри группы выполняются в любом порядке.
5. Нажмите **«Сохранить и открыть прохождение»**. Тренировка начнёт наблюдать действия автоматически.

Если после подготовки заданий меняли журнал или границы, снова создайте черновик. Авторские правки сохраняются;
конфликты и нарушенные зависимости нужно исправить до сохранения.

## Два разных вида групп

| Инструмент                   | Для чего                                                                     | Участвует в тренировке сейчас |
| ---------------------------- | ---------------------------------------------------------------------------- | ----------------------------- |
| Экраны обучения и переходы   | Разделяет сценарий на этапы; внутри этапа — свободный порядок заданий        | Да                            |
| Группы вариантов — заготовки | Сохраняет набор альтернативных элементов, например «Назад / Справка / Далее» | Пока нет                      |

Для обычного сценария группы вариантов пока не нужны. Чтобы проверить этот инструмент, остановите запись, откройте
нужный экран приложения и раскройте **«Группы вариантов — заготовки»**. Нажмите **«Создать группу вариантов»**, выберите
элементы кликами и нажмите **«Готово»**. Повторный клик убирает элемент, Escape отменяет выбор. Реальные controls в
режиме выбора не активируются. Панель можно перенести влево или вправо.

Состав сохраняется в этом браузере и открывается через **«Изменить …»**. Пока это отдельные заготовки: они не входят в
экспорт учебного сценария и не задают его правила. Если элемент исчез, инструмент потребует выбрать его заново.

## Где задать обратную связь

**Свои сообщения об успехе и ошибке пока задать нельзя.** Настройка реакций вариантов и авторских сообщений ещё не
реализована. Это оставшаяся часть этапа 6, а не скрытая настройка админки.

Поле **«Подсказка»** в редакторе — помощь ученику при выполнении задания. Оно не является сообщением о результате
действия. Существующие статусы проверки в тренировке, например «Значение не совпадает», формирует runtime; настраиваемые
автором сообщения и их показ через Taiga UI Alerts будут добавлены отдельно.
