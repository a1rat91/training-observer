# Как пользоваться админкой сейчас

Откройте `/record`. Слева работает целевое приложение, справа — админка.

## 1. Запишите действия

Нажмите **«Начать запись»** и выполните нужный workflow слева. После ввода текста выйдите из поля — например, через Tab.
До выхода из поля текст ещё не считается завершённым вводом.

Во время записи доступны **«Остановить запись»**, журнал, настройки областей и **«Группы вариантов»**. Выбор элементов
временно приостанавливает запись; после «Готово» или отмены запись автоматически продолжается в том же журнале. Редактор
заданий появляется после остановки. Настройку сохранения значений выбирают до начала записи.

Если при входе в выбор поле ещё редактировалось, незавершённый ввод отменяется. После возврата измените значение и
выйдите из поля, чтобы записать новую попытку. Если нужно сохранить ввод до создания группы — сначала самостоятельно
выйдите из поля.

## 2. Проверьте журнал

Нажмите **«Остановить запись»**. Удалите лишние действия; ошибочное удаление можно отменить. Начинать запись повторно
для редактирования не нужно: эта кнопка создаст новый журнал вместо текущего.

После остановки можно пользоваться приложением и возвращаться на нужные экраны — эти действия больше не записываются.

## 3. Подготовьте сценарий

В блоке **«Подготовка сценария»**:

1. Проверьте последнее действие, до которого должен дойти ученик. По умолчанию выбрано последнее записанное.
2. Нажмите **«Выбрать результат в приложении»** и укажите видимый признак успеха. Остановка записи сама по себе не
   доказывает, что действие в приложении завершилось успешно.
3. В **«Экраны обучения и переходы»** отметьте действия, открывающие следующий этап, и их результаты. Например, «Далее»
   переводит к новым полям; просмотр справки может остаться заданием того же этапа.
4. Нажмите **«Создать черновик сценария»**. В каждой карточке проверьте текст задания, подсказку, ожидаемое значение и
   optional/зависимости. Без явных зависимостей поля внутри группы выполняются в любом порядке.
5. Нажмите **«Сохранить и открыть прохождение»**. Тренировка начнёт наблюдать действия автоматически.

Если после подготовки заданий меняли журнал или границы, снова создайте черновик. Авторские правки сохраняются;
конфликты и нарушенные зависимости нужно исправить до сохранения.

## Два разных вида групп

| Инструмент                 | Для чего                                                           | Когда влияет на тренировку                     |
| -------------------------- | ------------------------------------------------------------------ | ---------------------------------------------- |
| Экраны обучения и переходы | Делит сценарий на этапы; внутри этапа — свободный порядок заданий  | После сохранения сценария                      |
| Группы вариантов           | Набор альтернативных элементов, например «Назад / Справка / Далее» | После привязки к заданию и сохранения сценария |

## Сообщения для действия

В подготовленном черновике у нужного задания или перехода раскройте **«Обратная связь и варианты»**. Заполните
**«Сообщение об успехе»**; у ввода/выбора также доступно **«Сообщение при неверном значении»**. Пустое сообщение не
показывается. Подсказка остаётся отдельной помощью ученику.

Успех сообщается после проверки результата. Для текстового поля ошибка появляется после выхода из него, для
radio/checkbox — после подтверждённого изменения, для перехода успех ждёт условия результата. Обновления DOM и повторные
проверки не создают новых уведомлений. В тренировке сообщения показываются через Taiga UI Alerts.

## Альтернативные действия

1. Откройте нужный экран приложения. Можно создавать группу прямо во время записи; останавливать её не нужно.
2. Раскройте **«Группы вариантов»**, нажмите **«Создать группу вариантов»**, задайте название и выберите элементы
   кликами. Реальные элементы при этом не активируются. Повторный клик убирает элемент, Escape отменяет выбор; панель
   можно переместить.
3. Нажмите **«Готово»**. Состав сохраняется в этом браузере; открыть его заново можно через **«Изменить …»**.
4. В карточке нужного задания или перехода раскройте **«Обратная связь и варианты»**, нажмите **«Привязать …»**.
5. Для ошибочных элементов включите **«Считать ошибочным вариантом»** и задайте **«Сообщение варианта»**. Остальные
   остаются допустимыми. Допустимому действию тоже можно задать нейтральное сообщение.
6. Для поля/выбора проверьте значение, при котором действует правило. У checkbox/radio переключатель задаёт включённое
   или выключенное состояние. У кнопки правило относится к клику.
7. Сохраните сценарий и проверьте его на странице тренировки.

**Ожидаемое действие уже задано записью.** Оно и другие ожидаемые действия этого экрана исключаются из добавляемых
альтернатив. Это сохраняет свободный порядок полей: другое правильное задание не становится ошибочным вариантом.
Альтернативы не засчитывают задание и не блокируют приложение; они действуют только для доступного задания активного
экрана. После выполнения/пропуска задания его альтернативы больше не проверяются. Переход должен быть доступен после
обязательных заданий.

**Пример:** ожидаемое действие — «Далее». «Справка» допустима, «Назад» отмечена ошибкой с сообщением «Продолжите
заполнение». Если справка обязательна, запишите её отдельным заданием — она не должна быть альтернативой.

Состав в инструменте выбора и привязанные правила — разные документы. Изменение сохранённого состава не меняет готовый
сценарий. В карточке можно убрать вариант или всю привязку; для нового состава удалите привязку и добавьте его заново.
Правила и сообщения экспортируются со сценарием v5 и сохраняются при пересборке после удаления соседних событий.
Конфликты запрещают сохранение; нельзя назначить противоположные правила одному действию в одном экране.

Пока нет автоматических предложений состава по DOM и проверки checkbox-набора как единого ответа через визуальный
редактор. Ошибка на конкретном checkbox — только явно заданный запрет конкретного состояния. Неизвестный клик не ошибка;
неоднозначная цель не даёт авторского сообщения об ошибке ученика.

Визуальный редактор альтернатив сейчас задаёт одиночную строку или boolean. Массивы и нормализованные значения можно
задать в JSON сценария; отдельного редактора этих значений пока нет.
