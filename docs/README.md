# Документация

Для знакомства с проектом достаточно первых трёх документов. История этапов не является частью API
и не нужна ни приложению, ни разработчику для продолжения работы.

## Актуальные документы

| Документ | Для чего читать |
| --- | --- |
| [Архитектура](../ARCHITECTURE.md) | Пакеты, алгоритмы, поток данных и ограничения |
| [Разработчику](developer-guide.md) | Запуск, подключение, расширение и проверка |
| [Пользователю demo](demo-guide.md) | Запись, редактор и прохождение |
| [Оставшаяся работа](roadmap.md) | Незавершённые возможности без истории этапов |

В каждом пакете также есть README: [core](../libs/training-observer/README.md),
[модели](../libs/training-observer/models/README.md), [contracts](../libs/training-contracts/README.md),
[recording](../libs/training-recording/README.md), [runtime](../libs/training-runtime/README.md),
[demo](../projects/demo/README.md).

## Справочник

Подробности отдельных механизмов нужны при их изменении, а не для первого знакомства:

- [Покрытие контролов](reference/control-coverage.md), [логические контролы](reference/logical-controls.md),
  [form-контролы](reference/form-controls.md), [dropdown](reference/dropdown-observation.md).
- [Автоматическое наблюдение](reference/automatic-observation.md),
  [микрофронты](reference/microfrontend-observation.md), [диагностическая подсветка](reference/node-highlighting.md).
- [Измерение нагрузки](reference/load-testing.md).

Эти документы описывают DOM-наблюдение. Правила записи и оценки учебного ответа находятся в документации
recording/runtime; например, диагностический unknown выбора ComboBox не мешает сравнению его видимого текста.

## Архив

[archive/](archive/) сохраняет прежние планы, аудит и исследование исходного прототипа.
Это рабочие материалы с датами и результатами прошлых прогонов, а не обязательная «память» агента.
Их не нужно читать по порядку; они могут содержать отменённые решения и старые пути исходников.
Новые результаты и правила обновляются в актуальных документах, без добавления очередного журнала этапов.
