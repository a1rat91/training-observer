# Recording: административная логика без UI

`@training-observer/recording` строит журнал примера и компилирует его в сценарий.
Зависит от core/models и contracts. Не зависит от runtime, DOM или Angular. Angular-админка demo находится
в `projects/demo/src/app/pages/record` и управляет кнопками, сохранением, undo и редактором.

## API и структура

- `src/lib/state-recorder.ts` — StateRecorder: start, observe, snapshot, stop.
- `src/lib/recording-edit.ts` — removeRecordedEvent и recordingProblem.
- `src/lib/scenario-compiler.ts` — compileScenario.
- `src/index.ts` — публичные exports; типы документов импортируются из contracts.

Маршрут чтения: модели contracts → StateRecorder.observe → приватные фазы регистрации → compiler → editing.

## Запись

`start` требует ready-экран, очищает предыдущую запись и запоминает baseline подтверждений.
`observe` сначала принимает blur уходящего экрана, затем обрабатывает готовность/смену ключа, затем текущие поля.
Это сохраняет последнюю правку, даже если DOM уже удалён обработчиком перехода.

Начальные checkbox/radio записываются сразу, включая false. При новом посещении память этих значений сбрасывается.
Новые динамические поля тоже получают исходную запись. Для Input/Number/Select/ComboBox нужны blur-подтверждения.
Одинаковые состояния не добавляют строк. Loading ждёт, unavailable добавляет явный пропуск, redacted не сохраняется.
`stop` останавливает приём; `snapshot` возвращает копию, которую UI не может использовать для изменения регистратора.

## Компиляция

В неполной записи компиляция запрещена. Компилятор создаёт шаг на каждое посещение и хранит последнее значение
по точному сериализованному descriptor внутри посещения. Порядок экранов сохраняется, порядок полей не обязателен.
False не исключается. Radio пока представлены отдельными вариантами true/false.
Создаются редактируемые тексты по умолчанию. Ни публикация, ни запись в storage здесь не выполняются.

## Удаление и отмена

removeRecordedEvent возвращает новый документ, сохраняет visit и перенумеровывает sequence.
Потеря границы при оставшихся полях создаёт проблему качества. Общий unavailable нельзя удалить,
поскольку неизвестен состав пропущенных действий. Неподтверждённое отдельное поле можно явно исключить.
Undo находится в Angular-админке: сохранённые снимки документа — Memento без обратных DOM-команд.

## Интеграция

Создайте recorder на одну административную запись. Перед Stop дождитесь рендера обработчиков,
вызовите observer.flush(), передайте последнее состояние в observe и затем stop.
Отдельно отредактируйте результат compileScenario и явно опубликуйте. Подробный пример —
[руководство](../../docs/developer-guide.md), пользовательский процесс — [demo](../../docs/demo-guide.md).

Пакет не решает распознавание кликов без результата, ветвления и редактирование групп.
Старая запись не дополняется новыми исходными полями автоматически.
