# Training Observer

Технический spike системы обучения поверх существующего Angular-приложения. Работа идёт по [плану](docs/spike/PLAN.md):
этапы 1–2 завершены, следующий — плеер процедур с динамическими формами.

Angular 19, Nx 20, Taiga UI **4.98.0**. Прежняя библиотека удалена; черновики `libs/element-spike` и
`projects/demo/src/pages/spike` ещё не приняты и к demo не подключены.

## Запуск demo

```sh
npm ci
npm start
```

Откройте [Исследование locators](http://localhost:4200/spike/research), либо пункт меню **Spike → Исследование
locators**. Корневой адрес перенаправляет на эту страницу.

| Маршрут              | Содержимое                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------- |
| `/spike/research`    | Живая форма Taiga UI 4, генерация locators по клику, проверка CSS, Driver.js, rrweb и сохранённый отчёт |
| `/examples/controls` | Существующий пример контролов                                                                           |

На странице исследования нажмите на поле или кнопку, чтобы увидеть доступное имя и locators. Кнопка «Подсветить»
показывает цель, «Начать запись» включает журнал значений полей с источниками snapshot/native/rrweb. Ниже — результаты
отдельного Playwright-прогона; они не пересчитываются при взаимодействии с формой.

## Проверки

```sh
npx playwright test tests/research.spec.ts
npm run research:spike
```

Нужен установленный Google Chrome. Первый тест проверяет маршрут и живые взаимодействия, второй запускает сравнительный
эксперимент библиотек и сохраняет результаты в `dist/spike-research/`. [Исследование](docs/spike/research.md) описывает
методику, ограничения и версии окружения.

Собственный resolver пока не измерен. Плеер с HTTP backend, семантический recorder, сценарный runtime и общий benchmark
выполняются следующими этапами. Прежняя команда `npm test` ссылается на удалённую библиотеку; для текущей проверки
маршрута используйте команду Playwright выше.
