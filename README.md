# Training Observer

Технический spike системы обучения поверх существующего Angular-приложения. Работа идёт по [плану](docs/spike/PLAN.md):
этапы 1–3 завершены, следующий — контракты наблюдения и записи.

Angular 19, Nx 20, Taiga UI **4.98.0**. Прежняя библиотека удалена; черновики `libs/element-spike` и
`projects/demo/src/pages/spike` ещё не приняты и к demo не подключены.

## Запуск demo

```sh
npm ci
npm start
```

Откройте [Плеер процедур](http://localhost:4200/spike/procedure), либо пункт меню **Spike → Плеер процедур**.
`npm start` запускает Angular и тестовый HTTP backend на порту 4310. Нажмите «Новая процедура» и пройдите заявку.
[Описание плеера и режимов сервера](docs/spike/procedure-player.md).

Исследовательская страница доступна через **Spike → Исследование locators**; корневой адрес пока перенаправляет туда.

| Маршрут              | Содержимое                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------- |
| `/spike/procedure`   | Плеер динамических форм: две ветки, HTTP backend, ошибки, возврат и завершение                          |
| `/spike/research`    | Живая форма Taiga UI 4, генерация locators по клику, проверка CSS, Driver.js, rrweb и сохранённый отчёт |
| `/examples/controls` | Существующий пример контролов                                                                           |

На странице исследования нажмите на поле или кнопку, чтобы увидеть доступное имя и locators. Кнопка «Подсветить»
показывает цель, «Начать запись» включает журнал значений полей с источниками snapshot/native/rrweb. Ниже — результаты
отдельного Playwright-прогона; они не пересчитываются при взаимодействии с формой.

## Проверки

```sh
npm run test:procedure-api
npx playwright test tests/procedure.spec.ts tests/research.spec.ts
npm run research:spike
```

Нужен установленный Google Chrome. Node-тесты проверяют серверный протокол, Playwright — маршруты и живые
взаимодействия. `research:spike` запускает сравнительный эксперимент библиотек и сохраняет результаты в
`dist/spike-research/`. [Исследование](docs/spike/research.md) описывает методику, ограничения и версии окружения.

Собственный resolver пока не измерен. Семантический recorder, сценарный runtime и общий benchmark выполняются следующими
этапами. Прежняя команда `npm test` ссылается на удалённую библиотеку; для текущей проверки маршрута используйте команду
Playwright выше.
