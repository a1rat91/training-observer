Запись процедуры

Начните запись, затем найдите процедуру, выберите её и заполните открывшуюся форму. Новая запись заменяет предыдущую. Скачайте JSON перед уходом со страницы. Текст поля записывается после выхода из него — например, клавишей Tab.
